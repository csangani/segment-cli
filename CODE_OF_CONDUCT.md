# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. Everyone who participates in this project is expected to follow it: in issues, pull requests, discussions, and any other project space.

In short:

- Be welcoming, patient, and respectful.
- Assume good intent, give constructive feedback, and accept it gracefully.
- Harassment, personal attacks, discriminatory language, and publishing others' private information are not acceptable.

## Reporting

If you experience or witness unacceptable behavior, report it to the project maintainer privately:

- through the contact options on the maintainer's GitHub profile ([github.com/csangani](https://github.com/csangani)), or
- with GitHub's **Report content** option on the comment, issue, or pull request in question.

All reports will be reviewed and handled confidentially. Maintainers may remove, edit, or reject contributions, and may temporarily or permanently ban contributors whose behavior violates this code of conduct.
